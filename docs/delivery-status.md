- 推荐理由、最低价未采用解释、来源原文；

## 已知限制

1. 料号别名和确定性邮件解析针对 bundled fixture，不是通用电子料主数据系统。
2. 模型输出有 schema 和来源校验，但仍可能漏抽；漏抽会降低覆盖率，不会自动补造。
3. 当前单次完整实时请求最多约 60 秒；三分钟现场演示前应先跑 provider 预检。
4. 当前离线包是一次真实 OMA 历史捕获，但打开回放本身不调用模型，不能描述成“本次实时执行”。
5. CSV 解析器不覆盖复杂 Excel 单元格、公式、多 sheet 或宏。
6. 汇率、13% 税率和 8% 毛利阈值都是模拟规则。
7. “资质已核 / 待核”来自 fixture，不代表真实渠道认证。
8. 页面状态只存在于当前浏览器内存，刷新即重置。
9. 客户报价草稿未包含物流、资金、关税、保修或账期。
10. UI 面向桌面演示，最低视口宽度 1080px。
